# dockerVulnPlex-Plex2Shell

## Author: J4ck3LSyN

Used for testing `plex2shell`... 

_Note: You must activate plex via /web locally for it to work..._

## Usage:
```sh
git clone https://github.com/J4ck3LSyN-Gen2/dockerVulnPlex-plex2shell.git
cd dockerVulnPlex-plex2shell
mkdir -p media plex-config # establish config
docker compose up -d --build
```

If you run into issues, check your firewall.
